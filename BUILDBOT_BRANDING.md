## 🎨 Visual Identity

### Logo Concept

**Name:** HZ Monogram  
**Style:** Bold, geometric, modern  
**Design:** 
- Clean sans-serif letters "H" and "Z" 
- Overlapping or interlocking style (represents connection)
- Scalable to any size
- Works in single color and multi-color

**Logo Variations:**
1. **Full Logo:** HZ monogram + "BuildBot AI" text
2. **Square Logo:** HZ in square (app icon, 1:1 aspect ratio)
3. **Favicon:** HZ initials (16px, 32px, 64px)
4. **Icon Badge:** HZ on gold/navy circle background

**Construction Details:**
- H and Z should have equal visual weight
- Golden ratio for proportional spacing
- Works at 16px (favicon) to 512px (large formats)
- Primary Color: Navy #1E2952 
- Accent Color: Gold #D4AF37
- Alternative: All Navy or Navy + Gold combination
- Recommended typeface: Inter Bold or similar geometric sans-serif

## 🔤 Typography

### Fonts

**Primary Font: Inter** (Modern, geometric)
```
URL: https://fonts.google.com/specimen/Inter
Usage: Headers, UI elements, body text
Weights: 400 (Regular), 500 (Medium), 600 (Semibold), 700 (Bold)
```

**Fallback:** -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif

### Font Hierarchy

```
H1 (Page Titles)
- Font: Inter, 32-36px, 700 Bold
- Color: Navy (#1E2952)
- Line Height: 1.2
- Example: "NEXUS Build"

H2 (Section Titles)
- Font: Inter, 24-28px, 600 Semibold
- Color: Navy (#1E2952)
- Line Height: 1.3
- Example: "Features"

H3 (Subsection Titles)
- Font: Inter, 18-20px, 600 Semibold
- Color: Navy (#1E2952)
- Line Height: 1.4

Body Text
- Font: Inter, 14-16px, 400 Regular
- Color: Gray (#4B6268)
- Line Height: 1.6
- Letter Spacing: 0

Button Text
- Font: Inter, 14px, 600 Semibold
- Color: Navy (#1E2952) or White
- Transform: Capitalize
```

## 📄 Brand Copy Guidelines

### Tone & Voice
- **Professional** — Trusted, expert knowledge
- **Approachable** — Clear, jargon-free language
- **Encouraging** — Empowering users
- **Local** — Respectful of Nigerian context

### Key Phrases

**Avoid:**
- "NEXUS Build" (old name)
- "BuildBot" (very old name)
- "Just click a button"
- "It's magic"

**Use:**
- "BuildBot AI"
- "Generate professional plans in minutes"
- "AI-powered construction planning"
- "Nigerian Building Code compliant"
- "Professional specifications instantly"
- "Built by HARZ Construction"

### Tagline Variations

**Primary:** "Intelligent Specifications. Professional Plans."  
**Alternative:** "Professional Plans. Powered by AI."  
**For Marketing:** "The Future of Construction is Intelligent"  
**For Nigeria:** "Build Better with BuildBot AI"
