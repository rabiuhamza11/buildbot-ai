# BuildBot AI

AI-powered construction planning platform for Nigeria.

## Overview
Generates professional construction plans, cost estimates, material lists, and SVG floor plans — calibrated to July 2026 Nigerian market prices.

## Features
- AI-generated SVG floor plans for any room configuration
- Real-time Nigerian market cost estimation (July 2026)
- Full material breakdown (blocks, cement, roofing, finishes)
- Paystack payment tiers: N15,000 Basic | N45,000 Pro
- Admin dashboard for project management & reporting

## Pricing
- Basic: N15,000 — Floor plan + estimate
- Pro: N45,000 — Full spec + materials + report
